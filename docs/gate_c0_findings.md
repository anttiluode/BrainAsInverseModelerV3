# Gate C0 findings — a tiny state-bearing spike payload

Date: 2026-10-01  
Status: frozen full protocol result

## Question

Gate C0 asked a deliberately narrow question:

> Does the waveform of an emitted spike add useful predictive information beyond the timing of the exact same spikes?

The passive V3 cable was left unchanged. Its soma voltage drove a fixed, one-way classical Hodgkin–Huxley emitter. Every primary reader used the same spike events, onset times, and waveform-availability times. The only extra information in the waveform arms was four measurements of the current spike: peak amplitude, half-height width, peak sharpness, and repolarization slope.

No hidden Lorenz coordinate entered forecast training. Readers were trained only against later observed `x` values.

## Viability

The fixed emitter passed the predeclared event-count gate without retuning. At zero input noise, the four held-out trajectories contributed **269, 266, 268, and 267** scored events respectively at the primary 20-sample horizon, well above the required 50 per trajectory.

Across the ten training/test trajectories there were about 268–279 detected spikes per 4,000-sample trajectory. Almost every detected spike yielded a valid waveform. The first eight valid candidates per trajectory were unavailable for scoring because eight completed ISIs were required; one training trajectory also lost one boundary waveform. There were no overlap or undefined-feature exclusions in the primary zero-noise condition.

## Primary result

Primary condition: zero input noise, forecast horizon 20.

| Receiver information | Mean NRMSE ↓ | Mean R² ↑ |
|---|---:|---:|
| Raw observed-input delays | **0.6301** | **0.5911** |
| Timing + residual waveform | **0.6554** | **0.5569** |
| Timing + real waveform | **0.6873** | **0.5128** |
| Internal cable state | 0.7483 | 0.4229 |
| Timing only | 0.7641 | 0.3980 |
| Timing + shuffled waveform | 0.7774 | 0.3768 |
| Current observed input | 0.8187 | 0.3094 |
| Waveform only | 0.8960 | 0.1731 |

Adding the real waveform to the eight-ISI timing context reduced mean NRMSE by **10.1%** relative to timing alone. It also beat the dimension-matched shuffled-waveform control by **11.6%**. The real waveform arm beat **both controls on all four held-out trajectories**.

Therefore the predeclared **C0-A criterion passed**.

## Timing-residualized waveform

The stronger control asked whether waveform information remained after predicting waveform shape from recent spike timing itself. Training-event residuals were generated out-of-trajectory: each training trajectory was residualized by a model fit to the other five. Held-out residuals were generated by a model fit only to all six training trajectories.

Timing + residual waveform reached **0.6554 NRMSE**, a **14.2%** improvement over timing alone, and beat timing alone on **all four** held-out trajectories.

Therefore the predeclared **C0-B criterion passed**.

The residual arm also performed better than the unresidualized waveform arm. That should not be read as “subtracting information creates information.” A more conservative interpretation is that removing the waveform component predictable from timing gave the fixed quadratic reader a cleaner coordinate system for the remaining state-dependent variation.

## Same-event control

The primary comparison does not confound waveform information with a different spike train. Timing-only, timing + real waveform, timing + shuffled waveform, and timing + residual waveform were all evaluated on identical event rows. The receipt records and verifies a shared event-identity digest for every trajectory.

The shuffled-waveform arm preserves every four-feature waveform vector exactly once within a trajectory while assigning it to a different event. Its primary NRMSE was **0.7774**, slightly worse than timing alone. The improvement therefore depends on the event-specific pairing between waveform and state, not merely on adding four more numerical columns.

## Negative control

An independent Gaussian label, which never affected the world, cable, emitter, or observations, was decoded from the richest primary feature set as a separate evaluation probe.

- mean NRMSE: **1.0453**
- mean R²: **−0.0417**
- predeclared chance check: **passed**

The positive C0 claims therefore remain valid under the frozen negative-control veto.

## What this means

Within this synthetic mechanism, active spike generation acts as more than a threshold producing a timestamp. The spike's fine waveform retains a small event-specific trace of the state that produced it, and that trace improves prediction of the later observed world beyond recent spike timing alone.

Operationally, the result supports the narrow picture:

```text
history-bearing dendritic state
    -> active ionic state
    -> spike time + small waveform payload
    -> more predictive receiver
```

The result is stronger than simply observing waveform variability: the useful part survives a same-spike timing control, a waveform derangement control, and a timing-residualized waveform control.

## What this does not mean

This does **not** establish that biological neurons generally use waveform coding, that the four simulated waveform features are a biological code, or that a downstream synapse can recover this information. The emitter is an illustrative one-compartment HH model driven by an artificial fixed soma-to-current map. There is no axonal propagation, presynaptic calcium/release model, postsynaptic neuron, or biological learning rule.

It also does not establish superiority over ordinary memory. **Raw observed-input delays remain better than the best waveform arm** at the primary horizon: 0.6301 versus 0.6554 NRMSE. The useful claim is about information surviving the emission transform beyond spike timing, not about replacing delay coordinates.

## Relation to Gate A

Gate A found that the passive cable retained predictive information internally while the declared scalar soma-history reader failed its output criterion. Gate C0 does not repair or overwrite that result. It tests a new output transform.

The combined result is now more specific:

1. useful history-dependent information exists inside the passive sender;
2. a simple scalar soma-history readout did not expose enough of it under Gate A;
3. a nonlinear active spike emitter can make a **small waveform payload** that exposes additional predictive information beyond the timing of the same spikes.

The next unresolved question is transmission: does that waveform distinction survive a biologically constrained presynaptic terminal/synapse and alter a receiver in a useful way? That is outside Gate C0 and requires a separately approved design.

The first two full-run process attempts were terminated by the execution harness before producing any receipt (120 s and 270 s wall-clock limits). No held-out result was written or inspected in either attempt. The identical frozen command was then allowed to run to completion without a fixed wrapper timeout. No model constants, features, thresholds, event rules, or readers were changed between those attempts.
